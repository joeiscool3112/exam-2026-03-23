# 🎬 Movie Search

Ứng dụng tìm kiếm thông tin phim miễn phí, giao diện hiện đại, hỗ trợ phân trang và xem chi tiết phim. Dữ liệu được lấy từ **OMDb API**.

## ✨ Tính năng chính

- Tìm kiếm phim theo tên
- Hiển thị danh sách phim dưới dạng card đẹp mắt
- Xem chi tiết phim (poster, thể loại, diễn viên, nội dung, rating, thời lượng)
- Phân trang thông minh (Prev / Next + Go to page)
- **Recent Searches** – Lưu lại các từ khóa tìm kiếm gần đây (lưu bằng localStorage)
- Click vào tiêu đề "Movie Search" để reset về trang chủ
- Giao diện responsive (đẹp trên cả máy tính và điện thoại)
- Dark theme hiện đại với màu tím gradient

## 🛠 Công nghệ sử dụng

- **React.js** (Functional Components + Hooks)
- **OMDb API** (`https://www.omdbapi.com/`)
- LocalStorage (lưu recent searches)
- CSS inline + responsive design

## 📸 Giao diện

- Trang chủ với ô tìm kiếm nổi bật
- Recent Searches (nút kính mờ)
- Danh sách phim dạng grid
- Modal xem chi tiết phim
- Pagination responsive
